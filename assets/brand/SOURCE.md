- **Local file:** `tanner-trading-logo.png` (full Shopify original)
- **Derivatives:** `tanner-trading-logo-header.webp`, `tanner-trading-logo-home.webp`
- **Source URL (highest available):** https://tannertrading.com/cdn/shop/files/TTBadge1.png?v=1613680408
- **Also referenced on homepage as:** `TTBadge1_200x.png` / `TTBadge1_200x@2x.png` in the site header (`site-header__logo`, class without inverted)
- **Alt text on site:** “Tanner Trading”

- **Placement decision:** Self-contained badge (dark charcoal field, cream type, red shadow, teal outer frame). Reads on the app’s dark charcoal header without recoloring. **No recolor / no inverted redraw.**
